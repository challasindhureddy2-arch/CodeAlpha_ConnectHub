# ConnectHub – Social Media Platform

## About the Project

ConnectHub is a full-stack social media web application that allows users to connect with people, share posts and stories, interact through likes and comments, and discover other users through a simple and user-friendly interface.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
- JWT Authentication
- REST APIs

## Features

1. User Registration and Login
2. Secure JWT Authentication
3. View and Edit User Profiles
4. Create and View Posts
5. Delete Own Posts
6. Like and Unlike Posts
7. Add and View Comments
8. Follow and Unfollow Users
9. Explore and Discover People
10. Save Posts
11. Activity Updates
12. Share Text and Photo Stories
13. Automatic 24-Hour Story Expiration
14. View Story Viewers
15. React to Stories
16. Save Stories to Highlights
17. View and Delete Story Highlights

## Database

Database Name: `connecthub_db`

Tables:
- users
- posts
- comments
- likes
- followers

## How to Run

### Backend

1. Open the backend folder in the terminal.
2. Run `npm install`.
3. Configure the `.env` file with your MySQL credentials and JWT secret.
4. Start the backend using `npm run dev`.

Backend URL: http://localhost:3000

### Frontend

Open `frontend/index.html` using VS Code Live Server.

Frontend URL: http://127.0.0.1:5500/frontend/index.html

## Storage

- User accounts, posts, comments, likes and followers are managed using MySQL.
- Stories, story reactions and highlights are stored in browser localStorage.
