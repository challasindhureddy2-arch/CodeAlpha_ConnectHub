

# ConnectHub – Social Media Platform

## About the Project
ConnectHub is a full-stack social media web application developed for the CodeAlpha Internship Task 2. It allows users to share posts, connect with people, like posts, and comment on posts.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
- JWT Authentication

## Features
1. User Registration and Login
2. View and Edit User Profiles
3. Create and View Posts
4. Delete Own Posts
5. Like and Unlike Posts
6. Add and View Comments
7. Follow and Unfollow Users

## Database
Database Name: `connecthub_db`

Tables:
- users
- posts
- comments
- likes
- followers

## How to Run

### Backend
1. Open the backend folder in terminal.
2. Run `npm install`.
3. Configure the `.env` file with your MySQL details.
4. Run `npm start`.

Backend URL: `http://localhost:3000`

### Frontend
Open `frontend/index.html` using VS Code Live Server.

Frontend URL: `http://127.0.0.1:5500/frontend/index.html`
